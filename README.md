# 🎓 EduSchedule AI

### Organização escolar de um jeito mais simples.

O **EduSchedule AI** é um sistema web criado para facilitar algumas tarefas do dia a dia escolar, reunindo ferramentas de organização, planejamento e acompanhamento em um só lugar.

A ideia surgiu da necessidade de tornar processos como a elaboração de horários, o registro de frequência e o acompanhamento de notas mais práticos e organizados.

O projeto foi desenvolvido com foco na simplicidade, buscando oferecer uma interface intuitiva e funcionalidades que realmente possam ajudar na rotina escolar.

## 🚀 Funcionalidades

- **Gestão de alunos:** cadastro, edição, descadastro e reativação.
- **Gestão de professores:** cadastro e organização das disciplinas.
- **Horários escolares:** geração automática de grades, considerando a disponibilidade dos professores.
- **Controle de frequência:** registro de presenças, faltas e acompanhamento dos percentuais.
- **Notas e médias:** lançamento de notas e cálculos automáticos.
- **Registro de acessos:** identificação dos participantes e acompanhamento dos acessos ao sistema.

## 💻 Tecnologias utilizadas

- Python e Flask — desenvolvimento do sistema.
- SQLite — armazenamento das informações.
- HTML e CSS — estrutura e aparência das páginas.
- JavaScript — interatividade e funcionalidades da interface.

## ⚙️ Como executar

É necessário ter o Python instalado.

1. Clone ou baixe este repositório.
2. Instale as dependências com `python -m pip install Flask`.
3. Configure a variável de ambiente `EDU_ADMIN_PASSWORD` com uma senha segura.
4. Execute o comando `python app.py`.
5. Acesse `http://127.0.0.1:5000` no navegador.

## 📌 Sobre o projeto

O EduSchedule AI está em desenvolvimento e pode receber melhorias conforme novas necessidades forem identificadas.

O objetivo é explorar como a tecnologia pode contribuir para uma gestão escolar mais organizada, acessível e eficiente.

**Observação:** esta é uma versão demonstrativa. Para testes, recomenda-se utilizar informações fictícias, evitando o cadastro de dados pessoais reais.
